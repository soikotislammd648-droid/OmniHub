# OmniHub

OmniHub is an all-in-one web platform MVP combining social, business, shopping, learning and creative tools.

## Included now
- Responsive landing page
- Social/messages interface
- Video/audio call placeholders
- Business and shopping demo
- Student/learning demo
- Drawing canvas with PNG save
- Mobile-friendly design

## Important
This is a **frontend MVP** that can be published with GitHub Pages.

Real:
- account registration/login
- real-time messaging
- video/audio calls
- business database
- orders/payments
- course storage and progress

require a secure backend and database. Do not put passwords, API secret keys or payment secrets in this frontend repository.

## GitHub Pages
After uploading the files:
1. Open repository **Settings**
2. Open **Pages**
3. Under the build/source option choose **Deploy from a branch**
4. Select **main** and **/(root)**
5. Save
6. GitHub will provide the public website address.
